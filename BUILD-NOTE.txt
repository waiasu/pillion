Pillion v34 + restart fallback fix

This is a complete Android Studio project. No patch application is required.
Open this folder as the project and build/install normally.

Restart fallback change only:
- Existing DashServer restart path remains unchanged.
- If DashServer helper is absent, ADB starts RestartHelper.
- Pillion waits for RestartHelper READY, then asks it to force-stop/relaunch Pillion.
- The old detached sleeping ADB-shell fallback is not used.
